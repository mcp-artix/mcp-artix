# Seeds (datos de laboratorio)

Insertar solo datos **ficticios**. Ejemplo:

```sql
INSERT INTO req_requerimiento (titulo, descripcion, solicitante, area, estado)
VALUES ('Demo: portal interno', 'Descripción sintética', 'usuario.demo', 'TI', 'borrador');
COMMIT;
```

No versionar dumps completos de bases productivas.
