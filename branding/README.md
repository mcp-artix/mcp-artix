# Branding institucional

Estructura preparada para sustituir placeholders por **logos, fuentes y colores oficiales** aprobados por comunicación institucional.

| Carpeta | Contenido |
|---------|-----------|
| `logos/` | SVG/PNG principales y variantes (claro/oscuro) |
| `icons/` | Iconografía alineada al manual de marca |
| `fonts/` | Archivos de fuente con licencia vigente |
| `colors/` | Derivados de paleta (`colors.json`) |
| `ui-kit/` | Descripciones de componentes (botones, formularios) |
| `css/` | Variables CSS generadas desde la paleta |
| `apex-theme/` | Notas y archivos de tema Universal Theme |

## Documentos guía

- [colors.json](colors.json)
- [typography.md](typography.md)
- [ui-rules.md](ui-rules.md)

## Uso en APEX

Importar variables de color y clases CSS desde `css/` o duplicar valores en **User Interface** según procedimiento interno.
